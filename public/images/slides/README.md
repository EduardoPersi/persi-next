# Imagens dos slides da Home

Armazene nesta pasta as imagens do carrossel principal da Home.

Ordem atual dos slides:

- `slide-01-impermeabilizantes-desktop.webp` e `-mobile.webp`;
- `slide-02-pex-gas-desktop.webp` e `-mobile.webp`;
- `slide-03-fortlev-desktop.webp` e `-mobile.webp`;
- `slide-04-pex-agua-desktop.webp` e `-mobile.webp`.

Os sufixos `desktop` e `mobile` identificam cada versão. O número após `slide`
define a ordem no carrossel. Use nomes sem espaços ou acentos para que o
`srcSet` seja interpretado corretamente pelos navegadores.

Preferir imagens em WebP ou AVIF, já otimizadas para a área em que serão
exibidas. Manter uma versão para desktop e outra para celular evita cortes
indesejados e reduz o tamanho transferido em dispositivos móveis.
